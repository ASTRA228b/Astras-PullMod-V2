# Astra's PullMod V2

Astra's PullMod V2 is a complete remake of my original PullMod, rebuilt with a cleaner system, better organization, more customization, and proper preset saving.

V2 keeps the general idea of the original PullMod while rebuilding a lot of the systems behind it instead of just changing the UI.

## Features

* Multiple pull modes

  * Stable
  * Dynamic
  * Strong

* Adjustable pull power

* Adjustable uphill power

* Momentum-based pull settings

* Maximum pull limit

* Optional velocity clamp

* Speed Boost

  * Adjustable jump speed
  * Adjustable jump multiplier
  * Speed Boost can work independently or alongside PullMod

* Input customization

* Left, Right, or Both hand modes

* Multiple activation modes

  * Release
  * Touch
  * Hold

* Preset system

  * Save custom presets
  * Load saved presets
  * Delete presets
  * Presets save PullMod, Speed Boost, input, hand, and other settings

* Tabbed UI

  * Pull
  * Speed
  * Settings
  * Presets

## Controls

`P` - Open / Close Astra's PullMod V2

The selected controller input is used to activate the pull system.

## Presets

V2 includes a proper preset system instead of only having hardcoded settings.

You can configure the mod how you want, enter a preset name, and save the configuration.

Saved presets can later be loaded or deleted directly from the Presets tab.

## Pull Modes

### Stable

A more controlled pull mode focused on predictable movement.

### Dynamic

Pull strength changes depending on your current momentum.

### Strong

A more aggressive version of the dynamic pull system for stronger movement.

## Speed Boost

Speed Boost is still included in V2.

You can control both:

* Jump Speed
* Jump Multiplier

It can also be configured to work independently from PullMod or only while PullMod is enabled.

## About V2

Astra's PullMod V1 was made as a simple customizable pull mod.

V2 is being rebuilt to make the mod easier to configure, easier to expand, and cleaner internally while still keeping the original PullMod idea.

A lot of V1's systems are being rewritten rather than directly copied into V2.

## Installation

1. Install BepInEx for Gorilla Tag.
2. Download the latest Astra's PullMod V2 release.
3. Put the DLL inside your BepInEx `plugins` folder.
4. Start Gorilla Tag.
5. Press `P` to open the menu.
